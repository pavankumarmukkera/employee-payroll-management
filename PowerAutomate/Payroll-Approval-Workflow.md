# Employee Payroll Approval Automation

## Proposed Workflow

1. Employee submits a payroll request.
2. Power Automate receives the request.
3. Manager receives an approval notification.
4. Manager approves or rejects the request.
5. Request status is updated.
6. Employee receives a notification.

## Suggested Connectors
- Microsoft Dataverse
- Approvals
- Office 365 Outlook

## Status
Workflow design only.
Not an exported or deployed Power Automate flow.
